# Lattice-QCD metadata

This directory contains metadata-only source and dependency artifacts for the
Lattice-QCD aggregated-consistency incubator. It does not contain observable
values, quoted uncertainties, reconstructed covariance, or averages.

`fk_fpi_source_manifest.yaml` pins the bounded primary-publication set selected
from FLAG Review 2024. `fk_fpi_dependency_graph.yaml` records source-evidenced
lineage and conservative unresolved-dependence states. Neither file is a
numeric dataset or a scientific result.
