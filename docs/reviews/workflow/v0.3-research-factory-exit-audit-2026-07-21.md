## Decision

The evidence-facing capability criteria in the
[v0.3 roadmap](../../roadmap.md#v03--research-factory-and-dataset-publication-layer--capability-exit-met-release-decision-pending)
are satisfied at the audited baseline. APL has a bounded shared Research
Factory protocol and schema, one reusable core exercised by Nuclear and
Materials adapters, a completed controls-first sprint that preserved negative
and inconclusive memory, and a source-pinned factory-compatible dataset with
citation, reuse, checksum, holdout, and replay metadata.

This is a capability-exit decision, not a software release decision. It does
not authorize a package-version change, tag, GitHub Release, Zenodo update,
broad announcement, claim promotion, or scientific reinterpretation. The
package remains `0.2.0` until the maintainer separately approves a release
preparation change and its release-time gates.

## Release Boundary

The audit supports a later maintainer decision to prepare `0.3.0`. A separate
release change must, at minimum:

1. rerun release-time technical, public-path, source-redistribution, citation,
   and public-wording gates at the exact release commit;
2. update `pyproject.toml`, `CITATION.cff`, and `.zenodo.json` together only
   after the maintainer approves the version transition;
3. prepare release notes that describe a bounded Research Factory capability,
   the negative first sprint, and the diagnostic-only second adapter without
   discovery wording; and
4. leave tag creation, GitHub Release publication, DOI metadata updates, and
   announcements as explicit maintainer actions.

`TASK-1066` and later scientific benchmarks are valuable science execution but
are not hidden prerequisites for this architecture milestone. Likewise, the
`TASK-1060` follow-up that converges the legacy Materials smoke script onto the
shared adapter is worthwhile deduplication, not an exit blocker: the shared
adapter already executes independently and matches the frozen lane science.

## Limitations

- The audit does not rerun every historical v0.2 opening probe against external
  GitHub settings; it relies on the committed exact-SHA opening signoff and
  rechecks current repository validation.
- The Materials adapter is a bounded diagnostic smoke, not a promoted RESULT or
  evidence of experimental materials performance.
- The Exoplanet adapter remains contract-only by design.
- No scientific claim, dataset row, metric, artifact review tier, or release
  identifier is changed.
